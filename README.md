# 성경 애니메이션 시리즈 제작표

대한예수교장로회 합동측 기준으로 창세기부터 요한계시록까지 66권을 숏폼(A타입)과 롱폼(B타입)으로 나눈 제작표입니다.

- `성경애니메이션_제작표.xlsx`: 최종 제작표
- `data/*.txt`: 분할 원본 데이터 (형식은 `data/01_율법서.txt` 맨 위 주석 참고)
- `scripts/build_xlsx.py`: 원본 데이터로 엑셀을 다시 만드는 스크립트

데이터를 고친 뒤 다시 만들려면:

```
python3 scripts/build_xlsx.py
```

스크립트는 66권이 모두 있는지, 전체를 다루기로 한 책에 빠진 장이 없는지 검사한 뒤 엑셀을 저장합니다.

## 시즌 구성

- `data/시즌1_선정.lst`: 시즌 1(약 6개월)에 올릴 편 목록. 여기에 없는 편은 자동으로 시즌 2에 배정됩니다.
- 업로드 규칙: 구약 매일 1편, 신약 주 4편(월·수·금·토).
- 엑셀의 `누락점검` 시트에서 시즌 1 + 시즌 2가 전체와 같은지, 중복·미배정·회차 연속성을 확인할 수 있습니다.
