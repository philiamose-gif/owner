# 프로젝트2 · 말씀 숏폼

성경 66권 핵심 구절 728편(구약 364 · 신약 364)을 6개월(182일) 동안 올리는 제작표입니다.

- `data/구약.txt`, `data/신약.txt`: 구절 목록 (책|장:절|주제|설명란 문구)
- `build.py`: 제작표 생성. 66권 포함 여부, 트랙별 편수, 성경 순서, 중복, 장 번호를 검사한 뒤 저장합니다.
- `말씀숏폼_제작표.xlsx`: 결과물

```
python3 project2/build.py
```

본문은 개역한글판 원문을 `구절목록` 시트의 노란 칸에 붙여 넣고 장절별로 대조합니다.
