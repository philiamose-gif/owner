# 프로젝트2 · 5분 성경읽기

개역한글 성경 전체(창세기~요한계시록)를 성인이 자연스럽게 소리 내어 읽어 5분 안팎이 되도록 나누고,
구약·신약 두 트랙으로 6개월(182일) 동안 하루 4~6편씩 올리는 제작표입니다. 각 편의 TTS 대본이 함께 들어 있습니다.

- 분할 기준: 1분 300음절, 장이 끝나는 곳에서 먼저 끊고 장 안에서는 문장이 끝나는 절에서만 끊음. 7분 30초 이하인 짧은 책은 한 편
- 본문: `reference/krv.tsv`(개역한글)에서 자동 생성. 별도 구절 목록 파일 없음
- `build.py`: 제작표 생성. 성경 전체 절을 순서대로 한 번씩 덮는지, 편 길이, 일정 겹침을 검사한 뒤 저장
- `5분성경읽기_제작표.xlsx`: 결과물 (읽기목록, 일자별, 권별점검, 누락점검, 제작템플릿, 성과기록)

```
python3 project2/build.py          # 제작표
python3 project2/build.py --tts    # + project2/tts/ 편별 TTS 대본 텍스트 (git 제외)
```
